# 46.3.1 Public MCP Tool Surface Review

The task specifies ten public tools; the registered runtime surface contains eleven, including `analyze_cdl_histogram`. The descriptions are action-oriented in `tools/__init__.py` or `tools/fppa_tools.py`, and the focused contract test checks every runtime description. Inputs and outputs are summarized from the callable signatures and response contracts.

| Tool | Public inputs | Output and status semantics | Agent-facing action / wrapper review |
|---|---|---|---|
| `analyze_cdl_histogram` | Polygon/MultiPolygon AOI, product vintage, qualifying CDL class values, optional no-data class values | `CDLHistogramResponse`; reports preliminary NASS CDL histogram evidence and invalid-input status | Meaningful categorical land-cover evidence action; explicitly does not establish active farming or an official FPPA/LESA determination. |
| `get_farmland_classification_by_point` | WGS84 latitude/longitude | `FarmlandClassificationResponse`; `coverage_status` is `covered`, `unmapped`, or `no_data`, with SDA source, regulatory notice, and structured source-aware error details on failure | Meaningful coordinate lookup and classification action; validation occurs before SDA access. |
| `get_farmland_classification_by_mukey` | Positive numeric SSURGO `mukey` | Same response and coverage semantics as point lookup, with SDA source, notice, and structured source-aware error details on failure | Meaningful map-unit classification action; delegates fixed lookup behavior to SDA client. |
| `analyze_farmland_by_polygon` | Polygon/MultiPolygon GeoJSON; NCCPI inclusion/index, optional positive county-rating override, optional map payload | `PolygonFarmlandAnalysisResponse`; includes coverage, source, authority, limitations, and the unchanged map contract | Meaningful integrated AOI screening and acreage analysis, not a REST pass-through. |
| `calculate_preliminary_lesa` | Project name, site/corridor geometry and type, productivity index, optional county benchmark, structured Site Assessment facts/overrides, corridor buffer settings | `PreliminaryLESAResponse`; preserves LE coverage and Site Assessment/threshold evaluation states | Meaningful preliminary LE/SA workflow. Input model rejects unknown fields, invalid criterion numbers, conflicting facts/overrides, and out-of-range values. |
| `get_soil_polygons_by_geometry` | Polygon/MultiPolygon GeoJSON, clipping flag, optional map payload | GeoJSON FeatureCollection with source, limitations and map metadata; expected failures include a source-aware structured error while retaining the legacy error text | Meaningful spatial retrieval and geometry/acreage transformation; not merely forwarding SDA rows. |
| `check_urban_area_exemption` | Project-footprint GeoJSON | `UrbanExemptionRecord`; status distinguishes success, unavailable, and error, with Census provenance and preliminary-screening limitations | Meaningful urban-boundary exemption screening action; internally delegates to TIGERweb client. |
| `get_soil_interpretations` | One or more positive `mukey` values, interpretation rule, `Weighted Average` or `Dominant Component` aggregation | Existing successful list-of-rating-records shape; expected SDA failures return an error status, source/endpoint, and structured error code/message | Useful component-rating retrieval action; internally delegates fixed/validated query construction to SDA client. |
| `analyze_corridor_fppa` | Centerline, positive buffer and one of feet/meters/miles, optional indirect geometry and strict alternative records, productivity options, structured Site Assessment inputs, optional map payload | Corridor response with coverage/reconciliation/source details and optional `lesa_evaluation` | Meaningful multi-county corridor screening and comparative-analysis action, not a thin client wrapper. |
| `explain_fppa_screening_scope` | No arguments | `FppaScopeResponse` with regulatory notice, limitations, and citations | Useful authority/scope reference action; no upstream REST wrapper. |
| `list_farmland_classes` | No arguments | `FarmlandClassListResponse` with class definitions and authority | Useful classification reference action; no upstream REST wrapper. |

## Deferred wrappers

No public wrapper is deferred by this task. The urban-exemption and soil-interpretation tools delegate to domain clients, but each exposes a complete, meaningful agent action and remains in scope; the soil-interpretation failure path is now explicitly source-aware. No separate owner/trigger is applicable.

## Validation evidence

Focused changes add bounded/enum/nested input validation, tests for unknown and malformed input, and source-aware SDA failure tests. The requested validation command is:

`uv run pytest tests\test_tools.py tests\test_models.py tests\test_server.py eval\contract\test_contract.py -q`
