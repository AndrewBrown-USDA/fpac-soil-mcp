# 44.1.2 -- Overlay probe from the deployed app origin

Plan 44 D5: the map loads a fixed overlay catalog (SSURGO WMS, TIGERweb
counties, TIGERweb 2020 urban areas) straight from the browser. This file
records the service metadata, a server-side probe sent with the app's
`Origin` header, and the browser check from the deployed app.

Probe points are arbitrary round-degree points (`-93.5, 42.0` and
`-93.6, 41.6`), not project or parcel locations. No response geometry is
copied here.

## Part 1 -- Service metadata (serverless, 2026-11-04)

### SSURGO WMS

- **Endpoint:** `https://SDMDataAccess.sc.egov.usda.gov/Spatial/SDM.wms`
- **GetCapabilities:** 200, 21 KB, `Access-Control-Allow-Origin: *`; WMS 1.0 and 1.1.1.
- **SRS:** `EPSG:3857`, `EPSG:4326`.
- **Map formats:** `image/png`, `image/png; mode=8bit`, `image/jpeg`, `image/svg+xml`, others.
- **Layers (all queryable):** `mapunitpoly` (Soil Mapunit Polygon), `mapunitline`, `mapunitpoint`, `surveyareapoly`, `surveyareapolyoutline`, thematic and extended variants.
- **Scale limits:** none declared in the capabilities. SSURGO polygons are only legible at about zoom 12 and closer; the client sets `minzoom` (choice for 44.8.2, not a service limit).
- **GetFeatureInfo `INFO_FORMAT`:** only `text/plain`, `text/html`, `gml2`. `application/json` and `application/vnd.ogc.gml` return 400 ServiceException.
- **GetFeatureInfo fields (`mapunitpoly`):** `areasymbol`, `spatialversion`, `musym`, `nationalmusym`, `mukey`, `muareaacres`, `mupolygonkey`. No `muname` or `farmlndcl`.
- **Response headers:** GetFeatureInfo has no `Content-Type` header; read it as text.

### TIGERweb counties

- **Endpoint:** `https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/1` ("Counties")
- **Capabilities:** `Map,Query,Data`; `supportedQueryFormats` `JSON, geoJSON, PBF`; `maxRecordCount` 100000.
- **Scale:** `minScale` 42000, `maxScale` 1001 (service draws only from about zoom 14 in; queries are not scale-limited).
- **Native SR:** 102100 (3857). Query with `inSR=4326&outSR=4326`.
- **Fields used:** `GEOID`, `NAME`, `STATE`, `COUNTY` (also `BASENAME`, `AREALAND`, `AREAWATER`).

### TIGERweb 2020 urban areas

- **Endpoint:** `https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/Urban/MapServer/0` ("2020 Urban Areas")
- **Capabilities:** `Map,Query,Data`; `JSON, geoJSON, PBF`; `maxRecordCount` 100000.
- **Scale:** `minScale` 6000000, `maxScale` 1001.
- **Native SR:** 102100 (3857).
- **Fields used:** `GEOID`, `NAME`, `UA` (also `POP100`, `HU100`).

## Part 2 -- Server-side requests with `Origin` set to the app (2026-11-04)

`Origin: https://agent-fpac-soil-openai-sdk-7474654188777746.aws.databricksapps.com`

| Request | Status | CORS header | Size | Notes |
|---|---|---|---|---|
| SSURGO `GetMap` `mapunitpoly`, EPSG:3857, 256x256 PNG | 200 `image/png` | `*` | 108 KB | |
| SSURGO `GetFeatureInfo` `INFO_FORMAT=text/plain` | 200 (no content type) | `*` | 270 B | one feature, fields above |
| SSURGO `GetFeatureInfo` `INFO_FORMAT=gml2` | 200 (no content type) | `*` | 4.6 KB | includes polygon coordinates |
| TIGERweb counties `query`, point, `f=geojson`, `returnGeometry=true` | 200 `application/geo+json` | echoes app origin | 43 KB | 1 Polygon, 1050 vertices |
| TIGERweb urban `query`, point, `f=geojson`, `returnGeometry=true` | 200 `application/geo+json` | echoes app origin | 232 KB | 1 MultiPolygon, 5694 vertices |
| TIGERweb `OPTIONS` preflight | 200 | none | | simple GETs need no preflight; do not add custom headers |

Gotchas for 44.8.2 and 44.9.1:

- TIGERweb only sends `Access-Control-Allow-Origin` when the request has an
  `Origin` header (browsers always send one on cross-origin fetch). Requests
  must stay simple GETs: no custom headers, or the failing preflight blocks them.
- SSURGO identify returns `mukey`/`musym` only. Farmland class and map-unit
  name need a lookup by `mukey`; the popup can show the raw fields and say so,
  or call an app route. Decide in 44.9.1 within its scope.
- A large urban area exceeds the 2000-vertex AOI cap (5694 here), so "Use as
  AOI" must show the D6 message for it. Counties fit at this sample.
- TIGERweb county map tiles are not drawn above about zoom 14 (`minScale`
  42000); draw counties from `query` GeoJSON or the
  `MapServer/export` image at a capped zoom range, not the cached map.

## Part 3 -- Browser check from the deployed app (user)

Open the deployed agent app, open devtools > Console, paste the snippet, and
paste the printed table back. Success means CORS allows the app origin; a
`TypeError: Failed to fetch` or image `error` means it does not.

```js
(async () => {
  const W = 'https://SDMDataAccess.sc.egov.usda.gov/Spatial/SDM.wms';
  const T = 'https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb';
  const merc = (lon, lat) => [lon * 20037508.34 / 180,
    Math.log(Math.tan((90 + lat) * Math.PI / 360)) * 6378137];
  const [x, y] = merc(-93.5, 42.0), d = 2000;
  const bbox = [x - d, y - d, x + d, y + d].join(',');
  const wms = (extra) => W + '?' + new URLSearchParams({ SERVICE: 'WMS', VERSION: '1.1.1',
    LAYERS: 'mapunitpoly', STYLES: '', SRS: 'EPSG:3857', BBOX: bbox, WIDTH: 256, HEIGHT: 256,
    FORMAT: 'image/png', ...extra });
  const tq = (path, lon, lat, fields) => `${T}/${path}/query?` + new URLSearchParams({
    geometry: `${lon},${lat}`, geometryType: 'esriGeometryPoint', inSR: 4326,
    spatialRel: 'esriSpatialRelIntersects', outFields: fields, returnGeometry: true,
    outSR: 4326, f: 'geojson' });
  const rows = [];
  const fetchRow = async (name, url) => {
    const t0 = performance.now();
    try {
      const r = await fetch(url);
      const body = await r.text();
      let note = '';
      try { note = `${JSON.parse(body).features.length} features`; }
      catch { note = body.slice(0, 40).replace(/\s+/g, ' '); }
      rows.push({ name, ok: r.ok, status: r.status, bytes: body.length, ms: Math.round(performance.now() - t0), note });
    } catch (e) { rows.push({ name, ok: false, status: 'blocked', bytes: 0, ms: 0, note: String(e) }); }
  };
  await new Promise((resolve) => {
    const img = new Image(); img.crossOrigin = 'anonymous'; const t0 = performance.now();
    img.onload = () => { let tainted = false;
      try { const c = document.createElement('canvas'); c.width = c.height = 1;
        const g = c.getContext('2d'); g.drawImage(img, 0, 0); g.getImageData(0, 0, 1, 1); }
      catch { tainted = true; }
      rows.push({ name: 'ssurgo_getmap_image', ok: !tainted, status: 'loaded', bytes: '-', ms: Math.round(performance.now() - t0), note: tainted ? 'canvas tainted' : `${img.width}x${img.height} usable as WebGL texture` }); resolve(); };
    img.onerror = () => { rows.push({ name: 'ssurgo_getmap_image', ok: false, status: 'error', bytes: 0, ms: 0, note: 'image load failed' }); resolve(); };
    img.src = wms({ REQUEST: 'GetMap', TRANSPARENT: 'true' });
  });
  await fetchRow('ssurgo_getfeatureinfo', wms({ REQUEST: 'GetFeatureInfo', QUERY_LAYERS: 'mapunitpoly', X: 128, Y: 128, INFO_FORMAT: 'text/plain' }));
  await fetchRow('tiger_counties_query', tq('State_County/MapServer/1', -93.5, 42.0, 'GEOID,NAME,STATE,COUNTY'));
  await fetchRow('tiger_urban_query', tq('Urban/MapServer/0', -93.6, 41.6, 'GEOID,NAME,UA'));
  console.table(rows);
  console.log(JSON.stringify(rows));
})();
```
