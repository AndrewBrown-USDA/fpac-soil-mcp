## Notes
- Files in scope are limited to `src/fpac_soil_mcp/http_client.py` and `src/fpac_soil_mcp/integration_models.py`; no other source or test files may be changed.
- `httpx>=0.27.0`, `pydantic>=2.0.0`, and Python >=3.11 are available.
- Existing clients (`SDAClient`, `TigerwebClient`, and `NassClient`) currently perform direct `httpx.Client` calls; this task creates the shared helper but does not integrate or refactor those clients unless explicitly added to scope.
- SDA currently uses exponential delays beginning at 0.5 seconds and treats non-5xx status errors as non-retryable; the new helper must follow the task's explicit default retry status set and configurable parameters.
- No new questions are blocking implementation based on the repository and task specification.
