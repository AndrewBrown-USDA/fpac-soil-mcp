## Notes

- `start_server.py` binds `setup_mlflow_git_based_version_tracking` by `from mlflow.genai.agent_server import ...` at import time, so patching the package attribute before import is enough. No app code changes (D3).
- In the module, `agent_server` is the `AgentServer` instance (it shadows the package name); the chat proxy builds `self.proxy_client` (httpx.AsyncClient) and calls `send(req, stream=True)`.
- Non-SSE proxied responses go through `aread()`/`aclose()`; a prebuilt `httpx.Response` supports both.
- A prior import of `agent_server.start_server` elsewhere would bypass the patch; only this test file imports it (grep).
