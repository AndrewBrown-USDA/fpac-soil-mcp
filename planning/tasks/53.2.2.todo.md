# Task 53.2.2 — Map navigation, boundary visibility, and line measurement

## Goal
Add map navigation and independent boundary visibility controls plus a cancellable, unit-selectable line measurement mode, without altering AOI data or server-rendered results.

## Tasks
- [x] Add distance/unit helper using a documented geodesic method, conversions, and defined empty/short-line behavior; add tests for known synthetic distances, each unit, and invalid/empty input.
- [x] Add testable map-control seams for bounds fitting and initial-view reset (small pure helpers or injectable map-operation callbacks in `MapPanel.tsx`); test AOI bounds passed to fit and reset to captured initial center/zoom.
- [x] Implement Zoom to AOI with existing `geometryBounds`/`fitBounds` semantics and Reset map using the initial `[-98, 39]`, zoom-3 view; handle absent AOI.
- [x] Add independent AOI-outline and returned-vector visibility controls with testable visibility/data separation; test hide/show changes layout visibility while retaining source data/features, with AOI and result state unchanged.
- [x] Implement those controls against `aoi-line` and returned vector layers only; preserve server map block rendering and ensure raster ordering is untouched.
- [x] Add distinct line-measurement interaction, visibly active state, line vertex collection, unit selection and displayed distance; measurement must not change Terra Draw AOI mode or geometry.
- [x] Add testable measurement lifecycle seam and tests for activation without AOI mutation, cancellation/clear, and restoration to static mode; prove cancellation discards the provisional line.
- [x] Add focused browser interaction coverage if a scoped MapPanel fixture is feasible. If not, document the fixture limitation and cover each control via pure/testable seams: bounds/initial view, visibility-vs-data, and measurement lifecycle/mode isolation.
- [x] Update ADR 0015 `### Local changes` for every modified or added vendored frontend path in this task.
- [x] Run exact targeted checks from `apps/agent-fpac-soil-openai-sdk/frontend`: `node --import tsx --test client/src/components/map/distance.test.ts client/src/components/map/mapControls.test.ts` and `npm run test:map-identify`; if a focused Playwright test is added, run its named script/config as well.
