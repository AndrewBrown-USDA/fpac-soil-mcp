## Notes
The existing fixed overlay catalog and `OverlayControl` handle raster context layers independently from analysis results; `MapResultContext` opens the panel for tool results, while current map-tool actions re-query through `/api/geo/map`. CDL returns a `CDLContextResponse` with optional zone results, per-zone classes (`class_value`, `class_name`, `pixel_count`, `share_pct`), status, coverage, vintage, source, provenance, and explicit limitations. Show only present server fields; do not imply missing values or completeness. ADR 0003 requires preliminary authority framing; ADR 0012 keeps the app a separate MCP client; ADR 0015 requires listing all local frontend changes; ADRs 0016 and 0017 govern AOI context and server map results. The task specification is limited to the named frontend files, app `AGENTS.md`, ADR 0015, and this planning file. Package manifests/lockfiles, MCP contracts, scoring, chat/session persistence, and other overlays are out of scope. The 50.1.2 dependency and Wave 1 gate are complete. No browser CORS verification was performed in this planning-only phase.
