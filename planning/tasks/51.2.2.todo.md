## Decisions incorporated from approval

1. Recognize questions and answers using the existing tool names
   `get_site_assessment_question` and `record_site_assessment_answer`; preserve
   the 51.1.2 answer-record fields. Confirm emits
   `{ type: "site_assessment_confirmed_summary", confirmed: true, answers }`,
   with `answers` containing the unchanged answer records. Do not invent a
   question/answer discriminator.
2. Reject a CDL result if no AOI is active or if the active AOI's `aoi_ref` or
   geometry differs from the AOI captured for that result. A reattached AOI
   with the same reference and geometry is equivalent; do not add a generation
   token.
3. Root plan decision D10 and task specifications in commit `752cbf7` are the
   contract.
