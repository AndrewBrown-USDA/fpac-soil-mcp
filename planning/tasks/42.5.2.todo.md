# 42.5.2 -- Agent: active AOI from `custom_inputs`

## Goal
When a chat request carries `custom_inputs.active_aoi`, the agent knows the AOI reference and summary, and tools called with that reference receive the geometry. Without it, behaviour is unchanged.
