## Notes

- `get_spatial_intersection(return_geom=True)` only adds `geom_data.geom.STAsText() AS geom` to the same per-fragment SELECT (no grouping change), so rows and acreage are the same.
- Polygon tests use a real `TigerwebClient` over `httpx.MockTransport`; the switch to the new method needs no edits there.
- Layer order is drop priority (the cap drops from the end): urban first, then farmland; the AOI is kept. The AOI legend uses the `outline` pattern; 44.6.1 should draw outline layers above filled ones.
- `urban_context` features are the full intersecting urban areas (context), not clipped to the AOI; large ones are handled by the cap.
