# 56.5.1 -- A: Edit-mode changes update attached geometry

## Goal
Every Edit-mode change to the AOI (drag, midpoint insert, vertex delete) updates the attached geometry; corridor Edit is checked by test only.

## Approach (chosen here, per D6)
Keep editing; do not disable midpoints/delete. Terra Draw 1.39 select mode already calls `onFinish` for `dragFeature`, `dragCoordinate`, `insertMidpoint` and `deleteCoordinate` (read from `dist/terra-draw.modern.js`), and `draw.on('finish')` already calls `replaceAoi`. The bug: that handler also removes every other snapshot feature, which in Edit mode includes Terra Draw's own selection-point and midpoint features. After the first edit, later midpoint/delete actions hit missing ids ("No feature with this id ... can not get geometry copy") and the attached geometry stops updating.

## Repro (probe in /tmp, not committed)
Draw square at known pixels -> Edit -> drag vertex: geometry updated, new ref. Then midpoint click: unchanged + 2 page errors. Then right-click vertex: unchanged + 1 page error.

## Discovered (out of scope)
