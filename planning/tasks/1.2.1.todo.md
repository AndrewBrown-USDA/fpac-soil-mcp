# 1.2.1 — Pydantic Models & Response Schemas

## Goal
Implement strong Pydantic data structures and response schemas for soil map units and FPPA screening responses in `src/fpac_soil_mcp/models.py`.

## Proposed Models
1. `SoilMapUnit` (BaseModel):
   - `mukey: str`
   - `musym: str | None = None`
   - `muname: str | None = None`
   - `farmlndcl: str | None = None`
   - `areasymbol: str | None = None`
   - Config / Field metadata where appropriate.
2. `QuerySource` (BaseModel):
   - `service_name: str` (default: "USDA NRCS Soil Data Access (SDA)")
   - `endpoint: str`
   - `timestamp_utc: str`
   - `documentation_urls: list[str]`
3. `FarmlandClassificationResponse` (BaseModel):
   - `query_type: str` (e.g., "point" or "mukey")
   - `input_query: dict[str, Any]` (e.g., `{"latitude": 42.03, "longitude": -93.62}` or `{"mukey": "12345"}`)
   - `coverage_status: str` (e.g., "covered", "no_data", "unmapped")
   - `map_units: list[SoilMapUnit]`
   - `source: QuerySource`
   - `limitations: list[str]`
   - `regulatory_notice: str`
4. `FppaScopeResponse` (BaseModel):
   - `title: str`
   - `summary: str`
   - `sda_screening_scope: dict[str, Any]`
   - `lesa_determination_scope: dict[str, Any]`
   - `regulatory_notice: str`
   - `limitations: list[str]`
   - `citations: dict[str, str]`
5. `FarmlandClassItem` / `FarmlandClassListResponse` (BaseModel):
   - `source: str`
   - `authority: str`
   - `classes: dict[str, dict[str, str]]`
