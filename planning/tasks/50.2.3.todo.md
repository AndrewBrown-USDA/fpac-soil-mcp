## Notes
- Files in scope: Can create `src/fpac_soil_mcp/clients/sda/{__init__.py,client.py,sdv_registry.py,sql_templates.py}`. Root file `src/fpac_soil_mcp/sda_client.py` is not modified or deleted (reserved for task 50.6.1).
- Dependency hierarchy: `clients/sda/` depends downward on `core` (`config`, `constants`, `errors`), `models` (`SUPPORTED_INDEX_MSG`), `spatial.geometry` (with fallback to `geometry`), and `clients.http` (with fallback to `http_client`). Zero dependencies on `domain` or `mcp`.
- Circular import prevention: Exception classes (`SDAClientError`, `SDAValidationError`, etc.) are defined at top-level in `client.py` before module-level imports of `sdv_registry` and `sql_templates`, ensuring `sdv_registry.py` and `sql_templates.py` can import `SDAValidationError` without initialization order cycles.
- Exception hierarchy: `SDAClientError` subclasses `DomainError`, `SDAValidationError` subclasses `(SDAClientError, ValidationError)`, and `SDAQueryError`, `SDATimeoutError`, `SDAServiceUnavailableError` subclass `(SDAClientError, UpstreamError)`.
- All new files satisfy `ruff check` and `ruff format`.
