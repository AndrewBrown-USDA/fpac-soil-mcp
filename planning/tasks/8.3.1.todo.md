## Notes
- `CountyPartitionGeometry` is a typed model that also supports dictionary index lookup `__getitem__` and `.get()` for backwards compatibility.
- Alternative alignments can have their footprint partitioned by `self.tigerweb_client.partition_geometry_by_counties(alt_footprint, alt_counties)` or directly evaluate county segments to compute area-weighted composite LE from segment NCCPI ratings.
- Reconciliation threshold is `0.1%` (`delta_pct > 0.1`). When violated, `limitations` must contain an explicit reconciliation warning message.
