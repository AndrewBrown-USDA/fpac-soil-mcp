# Plan 43.3.1 — Complete contract, live, and regression verification

## Goal

Verify the integrated Criterion 2 contract for site and corridor workflows,
including unavailable evidence, boundary behavior, live TIGERweb coverage, and
public evaluation expectations, without changing feature implementation.

## Steps

1. Review the 43.2.1 response shape and existing contract-test fixtures so new
   assertions use the accepted Criterion 2 field names and preserve the
   preliminary-screening notice.
2. Extend `tests/test_phase3_contracts.py` with deterministic site coverage for
   measured Criterion 2 evidence, awarded points, ratio bounds, rule/version,
   provenance, verification, and the 160-point threshold behavior.
3. Extend `tests/test_phase3_contracts.py` with deterministic corridor coverage
   for the buffered-corridor Criterion 2 result, corridor point limits, and
   preservation of existing county/alternative outputs.
4. Add contract cases for missing, unavailable, upstream-error, and measured-zero
   evidence, asserting unavailable/error are not serialized as measured zero and
   do not silently imply agricultural adjacency.
5. Add boundary-condition cases for ratio values at 0 and 1, just below/above
   the verified point thresholds, empty/boundary-touching geometry outcomes,
   and explicit Criterion 2 overrides.
6. Add or update a no-siting guidance assertion in
   `eval/prompt_test_cases.json` using the existing LESA-02 evaluation anchor;
   require preliminary framing and guidance to consider alternative
   non-farmland sites without changing unrelated cases.
7. Add an opt-in live test in `tests/test_live_tigerweb.py` for a known
   TIGERweb-covered footprint, asserting successful perimeter evidence,
   bounded ratio, provenance, and non-empty source metadata.
8. Make the live test skip explicitly on endpoint/network/unavailable responses;
   never convert live failures to zero adjacency and retain the
   `pytest.mark.live_network` module marker.
9. Run focused verification:
   `uv run pytest tests\test_phase3_contracts.py tests\test_live_tigerweb.py -q`
   (live test selected separately with `-m live_network`).
10. Run the exact offline regression gate:
    `uv run pytest -m "not live_network" -q`.
11. Run `uv run ruff check tests\test_phase3_contracts.py
    tests\test_live_tigerweb.py` and
    `uv run ruff format --check tests\test_phase3_contracts.py
    tests\test_live_tigerweb.py`; record results and any external live failure.
12. Record the completed files, commands, results, and deviations in this task
    record; do not modify feature code, unrelated eval cases, or default
    live-network selection.
