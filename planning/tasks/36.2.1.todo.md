# 36.2.1 -- Centralize executable fixture and assertion contracts

## Goal

Centralize executable deterministic cases in a versioned fixture while preserving the prompt/agent-evaluation corpus.

## Analysis findings

- `eval/prompt_test_cases.json` remains the authoritative Python prompt/agent corpus; `eval/run_evals.py`, `eval/test_agent_eval.py`, and the shared Databricks dataset loader consume it.
- `lib/evalCases.js` currently embeds executable arguments in `CASE_ARGUMENTS`, derives tool arguments through `TOOL_DERIVERS`, adds negative/validation `EXTRA_PRESETS`, and performs only keyword matching.
- Wave 1 is complete: the baseline report records the post-rebase compatibility requirement and `prompt_test_cases.json` preservation.
- The new fixture must be declarative JSON only: no executable expressions; predicate names must resolve through a JavaScript allowlist.
- Scope is limited to `eval/eval_cases.v1.json`, `lib/evalAssertions.js`, and `lib/evalCases.js`; scratch files, if needed, belong only in `.development/`.
