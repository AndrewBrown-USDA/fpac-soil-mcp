# 42.2.2 -- Map panel skeleton: deps, layout, draw/paste, Run screening, raw layers

## Goal
A collapsible map panel left of the chat where a user draws (polygon/rectangle, edit, undo, clear) or pastes/uploads one GeoJSON AOI, runs `POST /api/geo/screen`, and sees the AOI outline and clipped soil polygons coloured by `farmlndcl`.
