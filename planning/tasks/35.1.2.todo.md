## Notes
- Env is read at call time, so `monkeypatch.setenv`/`delenv` works without reloading.
- `load_system_prompt` follows `eval/databricks/agent.py` (UTF-8 read, `.strip()`) without versions or the forced-tool block.
- Timeout parse: `float(raw)`; a parse failure or a value `<= 0` leads to a single `ValueError` naming the variable (collect, then raise once, to avoid B904/TRY004).
- Root Ruff isort treats `agent_server` as third-party (no app `[tool.ruff]`), so it shares the import block with `pytest`.
- Orchestrator runs inline on this surface (no sub-agent spawning); plan self-reviewed against spec before execution.
