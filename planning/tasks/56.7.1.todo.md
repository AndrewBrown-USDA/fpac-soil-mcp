# 56.7.1 -- B2: drop late results; abort outline

## Goal
A map result that arrives after its chat or AOI changed is dropped; the Use-as-AOI outline request is aborted when its popup closes.

## Approach
- `ShowOnMapButton.tsx`: record `chatId` and `aoi_ref` when `run` starts; a ref holds the latest values; after each `await`, drop the result (stale message) if either changed.
- `IdentifyPopup.tsx` `AreaActions`: one `AbortController` per request, aborted on unmount (popup close unmounts it); same chat/AOI start-vs-latest check before `onUseGeometry`; an aborted request sets no state.
- `MapPanel.tsx`: reset corridor screening when `chatId` changes (its requestId guard then drops a late result).
- AOI screening: already guarded (requestId + AOI sync reset); regression test only.
