# 42.2.1 -- `/api/geo/screen` backend and privacy tests

## Goal
A stateless `POST /api/geo/screen` that calls the two deployed MCP tools without the model and returns browser-only `display` plus a geometry-free, allowlisted `chat_summary` and `chat_summary_text`, proven offline by marker, limit, error, no-trace and no-log tests.
